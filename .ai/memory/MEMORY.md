# Project memory – index

Knowledge gained while working on this project that is not in the specification (`docs/spec/`) or in ADRs. Rules: [`docs/spec/02-agent-rules.md`](../../docs/spec/02-agent-rules.md) §2.7 (Rule 7).

- Read this index at the start of every session.
- Read a topic file only when it is relevant to the current task.
- One line per topic file: `path` – what it contains – when to read it.
- Keep this index in sync with the folder contents.

## Topics

- `.ai/memory/backups.md` – restic exit codes and fixed host, Keycloak `admin-cli` tokens without `sub`, `pg_restore --create`, database passwords after a restore, Compose `required: false`, `config --images` and pulls of local images, the host gateway in tests, `gosu` in the postgres Alpine image, rclone without a configuration file, `set -e` in conditions – read when changing `docker/backup/`, the commands `backup`, `restore` or `update` of `./trybun`, or the restore test.
- `.ai/memory/bullmq.md` – BullMQ 6: forbidden job ID characters, ignored duplicate IDs, debounce deduplication for timers, a timer that delays itself again, queues injected into processors, retention and retries, Valkey compatibility – read when adding queues, jobs, timers or schedulers.
- `.ai/memory/docker.md` – Docker Compose, images and infrastructure services: the maintainer's test installation on the agents' VPS, `up --wait` and one-off services, shared server image, Keycloak readiness, keycloak-config-cli versions, the sjp.pl dictionary archive, SeaweedFS credentials and its slow first write, ClamAV image configuration and its ZIP size limits, internal networks, PostgreSQL 18 volume path, Dependabot and image pinning – read when changing `compose*.yaml`, `docker/` or the infrastructure services.
- `.ai/memory/e2e.md` – Playwright E2E set-up: seeded sign-in and one-time code reuse, several seeded sign-ins, the end users of the portal, tour tests on two devices, the tablet project below the tablet breakpoint, WebKit system libraries, axe exclusions, Lighthouse over the DevTools protocol, what moves the simulated LCP, measuring the sign-in redirect, the test environment scripts of the QA skills, one-time codes in QA runs and agent-browser on the VPS – read when writing E2E tests, running QA, adding a key page or when the Lighthouse budget fails.
- `.ai/memory/github.md` – GitHub identity of agents: the maintainer's account through `gh auth login` and approval by workflow (ADR 0011), the ruleset without required approvals, the earlier GitHub App `dtk7c2-claude` and its helpers (until 2026-10-28), PR title as squash commit, the scope of every commit (`docs(agents)` for `.ai/runs/`, never `docs(runs)`), the DCO check and its exemptions, re-running CI, Cezar's merge button, safe pull request workflows – read before pushing, opening or merging a PR, or changing GitHub settings, workflows or releases.
- `.ai/memory/help.md` – user documentation and the help viewer: the generator run with Node's type stripping, committed help content and Prettier, MiniSearch term processing (`ł`), index passing to the client – read when changing `docs/user/` or the help viewer.
- `.ai/memory/i18n.md` – next-intl 4 without routing (Vitest resolves the client build, typed keys, nested providers replace messages, `@parcel/watcher`), JSON import attributes of the catalogues, Keycloak's Java MessageFormat, locale order of the login screen and the generated theme, `timeZone` in provider tests, toasts across a language switch – read when adding texts, languages or formatting, or changing the Keycloak theme.
- `.ai/memory/markdown.md` – the Markdown rule set `@trybun/markdown` and its renderers: double footnote prefixes, case-sensitive protocols, percent-encoded backslashes, unwrapped links, task-list checkbox names, highlight contrast, shared test tables, npm dependencies of inlined packages, the global `JSX` of `hast-util-to-jsx-runtime`, undo through `execCommand`, `Textarea` as a `Field.Control`, user-event and selections in story tests – read when changing Markdown rendering, the GFM editor or e-mail Markdown.
- `.ai/memory/keycloak.md` – keycloak-config-cli (checksum cache, substitution in comments, several files per realm, ignored user IDs), Keycloak `amr`, 2FA for a group, OTP credentials, back-channel logout timeouts, Auth.js 4 adapter and token flow, adding a seeded user to an existing local realm, users created through the Admin API (names, password policy errors, required actions), registration, identity-provider user creation and organization invitations of Keycloak 26.8, the invitation sign-ins (post broker login failing on a skipped condition, `amr` after the OTP set-up, client-scope condition, testing providers with a second realm) – read when changing `docker/keycloak/`, the sign-in, sessions, token validation, invitations or the Keycloak Admin API.
- `.ai/memory/nestjs.md` – NestJS 12 validation, serialization and OpenAPI pitfalls; ecosystem support of NestJS 12; nestjs-pino (logger tokens, one root logger per process, route template, request ID context), the order of guards and parameter decorators, the three root modules (API, Worker, command line), and multipart uploads with multer (per-request limits, UTF-8 file names, error codes, removal of stored files) – read when writing endpoints, uploads, gateways, request or response schemas, logging, or when adding a NestJS library or a platform module.
- `.ai/memory/prisma.md` – Prisma ORM 7 pitfalls: `latest` is the Prisma 8 release candidate, driver adapters, `prisma.config.ts`, client extensions and `@casl/prisma` (the extended `PrismaService`, subject types, rule reasons), creating a migration (`migrate diff` without a shadow database), braces in schema comments, partial indexes (also ignored by `migrate diff` when not unique) and triggers allowing one column change, expression indexes, the violated index of `P2002`, to-one relations in CASL conditions (`is`), generic `accessibleBy` filters of record descriptors, `ILIKE` of case-insensitive filters, TypedSQL status, transactions, the constraint of `P2003`, the immutable `activity_events`, lazy queries in race tests, deleting an original with its duplicate, the status check constraints of tickets – read when installing or updating Prisma, or changing the schema, queries or transactions.
- `.ai/memory/react-compiler.md` – React Compiler: set-up in Next.js and Storybook, incompatible library APIs (React Hook Form `watch()`, TanStack Table 8), diagnosing with `'use no memo'`, state adjusted while rendering instead of `set-state-in-effect` – read when a client component shows stale data or when adding a React library.

- `.ai/memory/security.md` – CSP nonce in Next.js (request header, hidden nonce attribute, Zod's `eval` probe and `jitless`, style attributes, proxy matcher), rate limits with `@nestjs/throttler` (named throttlers and `@SkipThrottle`, guard order, headers, Valkey storage failing open, `trust proxy`, E2E with one seeded user), session lifetimes against Auth.js sliding expiry – read when changing security headers, the CSP, rate limits or session lifetimes.
- `.ai/memory/shadcn.md` – shadcn/ui on Base UI: CLI flags, flavours of Drawer, Command and Toast, `asChild` → `render`, the `cn` package and custom text sizes, monorepo set-up, what base-nova components need adapting, testing Toast, focus guards and Drawer swipes, Popover anchors, close reasons and menu link items, the Field family on Base UI, Tabs panel transitions, padding inside a Drawer, the lazily mounted toaster, outline buttons on coloured surfaces, long dialog titles, clearing a Combobox and the observers of `ScrollFade`, toasts above overlays and at the top on phones, the focus ring colour and computed styles in story tests, scrolling to an element with an outside ring – read when adding or adapting components in `@trybun/ui` or building a form.
