**Administration** › **About** shows:

- **Version** – the version of Trybun installed on this server, in the form `MAJOR.MINOR.PATCH`. It is the version of the deployment package you installed or last updated to, and the one to name when you report a problem. The release notes of each version are on the [releases page](https://github.com/trybun/trybun/releases).
- **License** – Trybun is free software under the MIT License; the link opens the license text of the installed version.
