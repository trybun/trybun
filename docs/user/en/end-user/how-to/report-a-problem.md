---
title: Report a problem
description: Create a ticket for the team in two steps, from the home of your project.
views: ['/portal/projects/[projectId]', '/portal/projects/[projectId]/tickets/new']
---

1. Open your project. After signing in you are already there; if you can report to several projects, select the project in **Your projects**.
2. Select **Create ticket**.
3. In **Title**, describe the problem in one sentence.
4. Optionally, describe it in more detail in **Description**. The grey questions in the empty field – what happened, what you expected and how the team can reproduce it – help you remember what the team needs; they disappear when you start typing. You can format the text: see [Format text](../reference/formatting-text.md).
5. Optionally, attach screenshots, logs or documents: drag them onto **Description**, paste them, or select **Attach files**. See [Attach files](attach-files.md).
6. Optionally, choose who else can see the ticket in **Visibility**: **My organization** or **All customers**. See [Choose who can see your ticket](choose-who-can-see-your-ticket.md).
7. Select **Submit**.

Your new ticket opens, and a message confirms its identifier, for example `CP-12`. Unless you chose another visibility, only you and the team see it. Follow its progress in **My tickets**: see [Follow your tickets](follow-your-tickets.md).

If the project is archived, it shows a note instead of **Create ticket**: you can still read your tickets there, but not create new ones.
