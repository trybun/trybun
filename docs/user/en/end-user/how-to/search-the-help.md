---
title: Search the help
description: Find a help page by a word from its title or text.
views: ['/help']
---

1. Select the help icon (question mark) in the header, then **Help for this view**.
2. On the help page, select **All help topics**.
3. Type a word into the search field, e.g. *language*.
4. Select a page from the results.

The search also finds words that you have only started typing and words with small typos. You do not need to type Polish letters: *jezyk* finds *język*.
