**Administracja** › **Konta** pokazuje wszystkie konta: członków zespołu i użytkowników, także osoby zaproszone, które jeszcze nie przyjęły zaproszenia. Na telefonie każde konto jest kartą.

## Kolumny

| Kolumna | Znaczenie |
|---|---|
| **Imię i nazwisko** | Nazwa wyświetlana; **Jeszcze bez nazwy**, dopóki osoba nie przyjmie zaproszenia |
| **Adres e-mail** | Adres, którego używa konto; nie zmienia się przez logowanie przez GitHub, Microsoft lub Google |
| **Rodzaj** | **Zespół** – loguje się przez GitHub i jednorazowym kodem; **Użytkownik** – loguje się hasłem, przez Microsoft lub Google |
| **Stan** | Zobacz niżej; **Administrator** oznacza Administratorów |

## Stany

| Stan | Znaczenie |
|---|---|
| **Zaproszony** | Konto utworzyło zaproszenie, którego nikt jeszcze nie przyjął |
| **Aktywny** | Osoba może się zalogować |
| **Dezaktywowany** | Osoba nie może się zalogować ([dezaktywuj lub aktywuj ponownie konto](../how-to/deactivate-or-reactivate-an-account.md)) |
| **Zanonimizowany** | Dane osobowe konta zostały usunięte |

## Filtry i wyszukiwanie

Filtruj po **Rodzaju** i **Stanie** oraz szukaj po imieniu i nazwisku lub adresie e-mail. Filtry są częścią adresu strony, więc możesz zapisać przefiltrowaną listę w zakładkach lub ją udostępnić.

## Działania

Działania konta (**⋮**) oferują tylko to, co jest dla niego możliwe: **Dezaktywuj**, **Aktywuj ponownie**, **Nadaj rolę Administratora** i **Odbierz rolę Administratora**. Twoje własne konto nie ma działań.

**Zaproś** zaprasza osobę do projektu, organizacji lub roli Administratora; oczekujące zaproszenia konta oferują **Skopiuj nowy link** i **Odwołaj**, tak jak zakładka **Członkowie** projektu ([zaproś osoby do projektu](../../team/how-to/invite-people-to-a-project.md)).
