Ustawienia projektu otwierasz z **Projektów**. Strona ma trzy zakładki.

## Ogólne

| Ustawienie | Znaczenie | Kto może zmieniać |
|---|---|---|
| **Nazwa** | Nazwa projektu | Kierownicy projektu i Administrator |
| **Klucz** | Prefiks identyfikatorów zgłoszeń, np. `ERP` | Tylko Administrator; dla pozostałych tylko do odczytu |
| **Potwierdzanie rozwiązania** | Przełącznik: prosi zgłaszającego o potwierdzenie, że problem jest rozwiązany | Kierownicy projektu i Administrator |

Wybierz **Zapisz zmiany**, aby je zastosować.

## Członkowie

Lista pokazuje nazwę wyświetlaną, login GitHub i rolę każdego członka. Widzą ją członkowie zespołu projektu i Administrator; zarządzają nią kierownicy projektu i Administrator ([zarządzaj członkami projektu](../how-to/manage-project-members.md)).

## Strefa zagrożenia

Widoczna tylko dla Administratora: archiwizowanie, przywracanie z archiwum i usuwanie projektu ([utwórz, zarchiwizuj i usuń projekt](../../administrator/how-to/create-archive-and-delete-a-project.md)).
