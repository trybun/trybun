title: Potwierdź, że problem został rozwiązany
description: Jednym naciśnięciem przekaż zespołowi, czy rozwiązanie u Ciebie działa.

Gdy zespół rozwiąże Twój problem, może poprosić Cię o potwierdzenie. Zgłoszenie ma wtedy status **Wymaga Twojej odpowiedzi** i pokazuje na górze pytanie **Czy Twój problem został rozwiązany?**

1. Otwórz zgłoszenie z **Moich zgłoszeń**.
2. Wybierz **Tak, rozwiązane** albo **Nie, problem nadal występuje**.

Po wybraniu **Tak, rozwiązane** zgłoszenie zostaje rozwiązane. Po wybraniu **Nie, problem nadal występuje** zespół dalej nad nim pracuje. Twoja odpowiedź pojawia się w historii zgłoszenia.

Jeśli nie odpowiesz w ciągu 7 dni, Trybun uzna problem za rozwiązany.

Jeśli zespół lub Trybun już zamknął zgłoszenie, komunikat poinformuje, że Twoja odpowiedź nie jest już potrzebna.
