---
title: Przeszukaj pomoc
description: Znajdź stronę pomocy po słowie z jej tytułu lub treści.
views: ['/help']
---

1. Wybierz ikonę pomocy (znak zapytania) w nagłówku, a następnie **Wszystkie tematy pomocy**.
2. Wpisz słowo w pole wyszukiwania, np. *język*.
3. Wybierz stronę z wyników.

Wyszukiwanie znajduje też słowa, których początek dopiero wpisujesz, oraz słowa z drobnymi literówkami. Polskie znaki nie są wymagane: *jezyk* znajdzie *język*.
